A new project comes with an `AGENTS.md`: the framework's rules in one page, written for a coding agent that has only ever seen React, and a `CLAUDE.md` that points Claude Code at it. It covers what Gesso is not, why a component runs once and what that means for state, layout and theme tokens, channels, and how to check work you cannot see in the DOM. The documentation site now publishes `llms.txt`, `llms-full.txt` and a markdown copy of every page for the same readers.
