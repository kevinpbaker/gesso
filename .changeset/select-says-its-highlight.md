`Select` says which option its open list highlights: `onHighlight` hears the option's value each time the arrows, a typed letter or the pointer move the highlight, and `null` when the list closes, for showing what choosing an option would do before it is chosen. The highlight now follows the pointer too, as `Menu`'s does, so Enter takes the option under the pointer; a disabled option still never takes it. Found by Flatwright, whose "Flange on an edge…" list lights up on the drawing the edge each option names.
